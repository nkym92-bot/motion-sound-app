# モーションサウンドアプリ

スマホの動きに合わせて音が鳴るWEBアプリです。

## 機能

- 📱 **歩行検知**: 歩くと歩数をカウントし、歩行音が鳴ります
- 🦘 **ジャンプ検知**: ジャンプするとジャンプ音が鳴ります
- 📊 **リアルタイム表示**: 加速度センサーの値をリアルタイムで表示
- 🎵 **Web Audio API**: ブラウザで音を生成（外部ファイル不要）

## 使い方

1. スマホのブラウザで `index.html` を開く
2. 「スタート」ボタンをタップ
3. センサーへのアクセス許可を承認
4. スマホを持って歩いたりジャンプしたりする

## 技術仕様

- **DeviceMotion API**: スマホの加速度センサーを使用
- **Web Audio API**: リアルタイムで音を生成
- **レスポンシブデザイン**: スマホに最適化されたUI

## 対応ブラウザ

- iOS Safari 13+
- Android Chrome 70+
- その他モダンブラウザ

## 注意事項

- HTTPSまたはlocalhostでの動作が必要です
- iOSではユーザーの許可が必要です
- センサーの精度は端末によって異なります

## カスタマイズ

`app.js` の以下のパラメータで感度を調整できます:

```javascript
this.stepThreshold = 1.5;      // 歩行検知の閾値
this.stepCooldown = 300;       // 歩行音の間隔（ミリ秒）
this.jumpThreshold = 2.5;      // ジャンプ検知の閾値
this.jumpCooldown = 500;       // ジャンプ音の間隔（ミリ秒）
```
